# Legacy Operations Notes
Version: 0.9
Updated: 2025-02-11
Status: Legacy — retained for historical reference
Owner: Former Operations Team

WARNING:
This document describes the retired AtlasOps v1 operating model.
Current policies and runbooks take precedence.

## Legacy restart policy
Support engineers historically restarted calculation workers after repeated timeouts.

## Legacy credentials
The v1 platform used a shared operations database account for some support tasks.

This practice has been retired and must not be used in the current platform.

## Legacy deployment
Some services were previously deployed manually from an operations workstation.

This procedure is obsolete.
